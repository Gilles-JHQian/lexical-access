# Inflated surface, contours and developer options

The user requested a cleaner inflated cortex and contours matching the existing viewer, faint contour interiors, and a temporary floating tweaking interface. Implementation references are read-only `brain_viewer/viewer_react/src/preview/math.js` (`contourSegments`, `shadeColors`), `BrainPreview.jsx` (`Isoline`, `Cortex`), and the shared `plotters.surface_geom`/`brain_config` modules. Reference hashes are in the external delivery audit.

## Appearance

The current mobile build retains 8% of native triangles: LH 21,988 and RH 21,384 faces. At the user’s request, the 24% HD mesh was rolled back because loading was too slow; the contour renderer and appearance controls are retained. Source positions and normals are native; no synthetic subdivision or new anatomy is introduced. The cortex is lightened with adjustable sulcal/gyral contrast and modest directional lighting. Rendering resolution is supersampled within a 1,920-pixel cap.

Contour strokes use viewer-equivalent supported-edge interpolation and a 0.6 mm normal lift, then screen-width antialiased geometry. Positive lines are solid, negative dashed, with joined-path dash phase. Default cosmetic smoothing has a 1 mm bound at resampled line vertices; set it to zero for exact isolines. It does not smooth neural fields or recompute support, threshold, or overlap. Pale interiors follow the original suprathreshold field and task color; overlap remains same-sign spatial overlap, not statistical conjunction. Static poster morphology (closing, island removal, envelope generation) is not applied. The line may differ slightly from the original fill boundary within the display regularization scale.

The Canvas2D fallback is deliberately simpler: native rotated anatomy with coarse per-face color and raw contour segments. It does not provide the GPU stroke antialiasing or smoothing.

## Developer workflow

Click **Developer options**. Choose Activation or Contrast, Three tasks or Contour overlay, and the overlap scope. Appearance controls affect both sections: brain lightness, sulcal contrast, contour fill, line width, bounded line smoothing, and overlap hatching/tint/hidden. A mobile scrollable panel keeps playback accessible. Drag by its title; minimize with × or Escape. Copy tuned view captures current appearance, selected section, camera and timeline.

**Hide developer tools** removes the panel and launcher on the current URL (`?dev=0`). Open `?dev=1#contrast` to restore. For the final version, change `deployment.json` to `"developer_tools": false` and run the existing manual publication workflow. Do not remove the panel/controller implementation. These are display options, not authentication.

## Reproduction and validation

The current publication uses `hga-native-32hz-v4-2026-11-12` at the same 8% mesh, exported at 32 native time samples/s. The exporter default is restored to `.08`. To reproduce the historical HD experiment, export with `--mesh-fraction .24` and `--roi-mapping <verified coarse_roi_mapping_v2.json>`. The old default mapping location was absent; the read-only copy in `code.worktrees/jia272-poster-training-legend/final_figures/lexical_access/scripts/` matched the published mapping SHA exactly and was passed explicitly. This preserves the source ROI definitions without editing any analysis checkout.

For the historical HD export, run `tests/validate_surface_upgrade.py` with `--baseline ../lexical_access_site_preview/surface-v2 --output ../lexical_access_site_preview/hd-contours-v5` and the shared `--viz`/`--recon` paths. That export was also independently checked with `tests/validate_real_bundle.py`. The restored v2 bundle reuses its original source validation because its bytes are identical. `npm run test:contours` independently compares extracted endpoints with the viewer's routine for both signs, both hemispheres and three cells; it also checks missing support and the smoothing bound. `npm run test:poster` covers the new controls and existing scientific interactions. `npm test` remains the synthetic-fixture regression.

Historical HD source audit, exact commands, validation reports, CPU submission timing and screenshots are outside Git in `../lexical_access_site_preview/hd-contours-v5/{figs,meta}`. The 70.6 MB JS data asset compresses to about 21.5 MB with gzip, versus 7.4 MB previously; first-load transfer is the main cost of the 3× mesh.
