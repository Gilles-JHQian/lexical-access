# 项目介绍页大纲 · 最终 poster 叙事

依据 11 月 11 日最终稿 `sfn-poster-nov-ver5-affiliations.pptx`，替代早期 11 月 5 日草稿的三个独立成分叙事。来源核对见 POSTER_SOURCE.md。手机优先；保留原 Cogan Lab、Duke Biomedical Engineering 标志和现有字体。

| 章节 | 主线 |
| --- | --- |
| 封面 | Neural Dynamics of Lexical Access Across Response Demands |
| 01 研究问题 | 词汇通达中哪些加工跨任务共享，哪些依赖反应要求？ |
| 02 实验设计 | 相同 40 个词和 40 个伪词；22 名参与者；被动听、词汇判断、口头复述 |
| 03 HGA activation | 共同的听觉颞叶活动，以及主动任务较晚的额颞招募；独立动态演示 |
| 04 HGA contrast | 激活网络内的词／伪词差异；无需输出的加工与需求招募、跨输出方式共享的加工；独立动态演示 |
| 05 跨任务表征 | 一个任务训练、其他任务测试的线性词汇性分类；STG/STS 与腹侧颞叶／前额叶两层解释 |
| 06 结论 | 不要求行为输出也存在的成分，加上反应要求招募但跨输出方式共享的成分；下一步定量时序与编码模型 |
| 补充 | 作者、单位、三篇参考文献、两类固定分享入口 |

每章可折叠。Question、Activation 和 Contrast 默认打开。两个动态区各自保存时间、视角、对齐、半球和 ROI；单区内的三个任务同步旋转。三任务和 contour 两种展示继续保留，共同区域仅表示同符号空间重叠，不解释为统计 conjunction。

主界面移除 REAL DATA、BIPOLAR、PILOT 等徽标与重复的小字。必要的信号定义、样本数、固定选择窗口、kernel、显示阈值和局限集中到可展开说明。

完整叙事入口保持根网址；NFC `/hga/` 仍打开 activation，另有 `#contrast` 直达。历史 `#hga?metric=contrast` 链接兼容。未重新计算真实数据，也未新增解码数值或未提供的结论。
