# Lexical access · interactive poster companion

Mobile poster companion, published at [full story](https://gilles-jhqian.github.io/lexical-access/) · [activation / NFC](https://gilles-jhqian.github.io/lexical-access/hga/) · [contrast](https://gilles-jhqian.github.io/lexical-access/#contrast). The root and NFC addresses stay stable. Publication uses the existing manual Pages workflow.

The public narrative in `poster.html` follows the final November PPTX: What is Lexical Access? → Our Design → shared auditory activation → lexicality effects → cross-task representations → Take home message. Activation and contrast have separate interactive chapters and saved state. Each supports three task maps with synchronized rotation, contour overlays, onset/offset alignment, and hemispheres. Method/interpretation notes are expandable. See [source authority](docs/POSTER_SOURCE.md).

This standalone Avalon repository owns presentation code. Root `index.html`, `app.js` and `mock-data.js` remain the original synthetic development fixture (`npm run serve`). Generated real data, browser previews and reports are outside Git in sibling `lexical_access_site_preview/contrast-time-v11/{figs,meta}`. Open `meta/interactive-preview-real.html` for the standalone preview, or serve `meta/final-site/` for the Pages artifact. Playback uses 32 real time samples per second at 1×. The public page loads only the selected hemisphere/condition/time block and prefetches during playback. The aggregate build input is a checksum-pinned GitHub Release; there are no participant recordings, subject identifiers or individual-electrode browser arrays.

Original Altitude and Aelkahhaazh stimulus recordings load only on playback. The final poster decoding figure uses a lazy 246 KB WebP preview; its unchanged SVG opens in a scrollable enlargement on request. The separate static Contrast section switches between the poster’s Stimulus/Offset × PW > W/W > PW results, with both hemispheres, directional d′ curves and effect-contribution pies. Curve/ROI labels are sized for the web, with consistent scale across all four sets and a 360 px chart-width cap. The original descriptive traces were removed from both dynamic players; Activation has no static figure block. Figure enlargement opens fitted to the viewport and supports 25–400% zoom plus Fit. All presentation assets live in a separate checksum-pinned Release, not source Git. Public copy/share buttons have been removed. See [media provenance and preparation](docs/STORY_MEDIA.md).

Contrast also offers **Original**, **Smoothed · σ 50 ms**, and **SDR1 cluster mask** under **Developer options → Contrast signal**. Original remains the default comparison. Each alternative loads only when selected, preserves the current time/camera, and can be saved in a tuned URL. See [temporal comparison provenance](docs/CONTRAST_TEMPORAL.md).

The floating **Developer options** panel owns comparison mode, overlap, contour fill/width/smoothing and cortex lightness. It can be dragged, minimized, and hidden. `?dev=1` reopens it; set `developer_tools` to `false` in `deployment.json` for the final public presentation. Copy tuned view preserves appearance settings. See [Surfaces and developer tools](docs/HD_SURFACES.md).

## Validation

Install development-only Playwright with `npm install`, then `npx playwright install chromium`. `npm test` checks the synthetic fixture. `npm run test:poster` (also `test:real`, `test:pages`, `test:surface`) checks the public two-explorer experience. Set `SITE_POSTER_OUTPUT` to a delivery folder, `SITE_POSTER_ROOT` to a build directory, or `SITE_POSTER_URL` to an existing deployment. `npm run test:story` checks actual audio playback, lazy media boundaries, mobile figure enlargement and original media hashes. `npm run test:static` checks the four poster component sets, independent controls, deferred loading/retry and fitted zoom. `npm run test:temporal` checks the three Contrast signal options, saved links, playback, variant request isolation and retry. `npm run test:loading` checks 32 Hz demand loading and buffering. `npm run test:contours` verifies exact isoline extraction against the viewer and the display smoothing bound. Tests use ephemeral servers and save screenshots/reports outside Git. See [architecture](ARCHITECTURE.md), [development record](docs/DEVELOPMENT.md), [Pages build](docs/GITHUB_PAGES.md), [scientific export](docs/REAL_DATA_PILOT.md) and [Chinese outline](docs/OUTLINE.zh-CN.md).
